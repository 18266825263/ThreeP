# 慢岛 · 开源组件增强版

这里是完整的单文件放松空间，下载 index.html 后可离线使用，无需账号或安装。全部样式、程序和第三方许可已内嵌。

## 开启 GitHub Pages

1. 打开 https://github.com/18266825263/ThreeP/settings/pages
2. 在 Build and deployment 下，Source 选择 Deploy from a branch。
3. Branch 选择 main，目录选择 /docs，点击 Save。
4. 等待 GitHub 显示正式网站地址，再通过该地址分享。当前未完成这一步，不能把预计的 github.io 地址当作已经上线。

原 chatgpt.site 地址在用户网络下出现 Cloudflare 拦截，这不能通过前端代码解除。

## 实际使用的开源项目

- noisejs：https://github.com/josephg/noisejs，固定提交 9c53d7faed1c1a1d4c0927b238ff3def7bb8803b，ISC。用于自然云雾、山形和流场画笔。
- qrcode-generator：https://github.com/kazuhikoarase/qrcode-generator，js2.0.4 / 83b7e8fe3fddd3b0368dbafd6ce56995bd25e3c8，MIT。用于邀请二维码和邀请卡。

第三方完整许可保留在单文件 HTML 的 head 注释中。心事不上传、不保存，分享不包含心事与画布。
